02 — Modules

14 modules.
6 categories.

CONTROLS

  • Click GUI

    Opens this menu. Change the key with the Keybind button.

  • HUD Editor

    Drag, scale, enable and reset HUD elements. Wheel = scale, R = reset hovered.

01
VISUALS

  • Watermark

    Client name tag with optional FPS.

  • Reach Display

    Distance to your target. Decimals, update interval, label, target name, hide without target.

  • Armor HUD

    Vertical or horizontal layout, durability percent, held item.

  • Info HUD

    Ping, coordinates, facing, clock and FPS.

  • Item Status

    Shows if Pearl / Totem / Elytra shortcuts are ready.

02
COSMETICS

  • Aura

    Cosmetic particle aura around your character. Main and second color, speed, size, density, radius, opacity, first-person toggle.

03
PLAYER

  • Elytra Swap

    With inventory open: swap between elytra and chestplate. Anti-spam delay.

  • Pearl Swap

    Select the ender pearl in your hotbar; press again to go back.

  • Totem Swap

    Move a totem to the off-hand. Choose what happens with the inventory closed.

04
WORLD

  • Radius Circle

    A circle around the crosshair target. Radius, solid / dashed / double style, two colors.

05
CONFIGS

  • Profiles

    Switch, duplicate, create, save and reset configuration profiles.

  • Theme

    Presets, accent colors, panel opacity, text size, scale, bold, shadow, gradient, animations.

      05 — Install

      Four steps.
      One minute.

      1. 01

        Java 21+

        Make sure Minecraft runs on Java 21 or newer.

      2. 02

        Fabric Loader ≥ 0.18.0

        Install Fabric for Minecraft 1.21.11.

      3. 03

        Fabric API

        Required dependency. Put it in your mods folder.

      4. 04

        Drop in the .jar

        Copy delta-visuals-0.3.0.jar into mods, launch the game and open the ClickGUI.
